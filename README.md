# المجلس · Majlis

ثلاث ألعاب لوحية على جهاز واحد — إكس أو، لودو، الذاكرة. تطبيق ويب تقدّمي (PWA) يعمل دون إنترنت، بلا حساب وبلا خادم.

Three board games on one device — Tic-Tac-Toe, Ludo, Memory. An offline-first PWA with no account and no backend.

---

## المحتويات

```
index.html              التطبيق كاملاً (واجهة + منطق الألعاب)
privacy.html            سياسة الخصوصية (عربي/إنجليزي)
manifest.webmanifest    ملف التعريف الذي يسمح بالتثبيت كتطبيق
sw.js                   عامل الخدمة — التخزين المؤقت والعمل دون إنترنت
icons/                  أيقونات التطبيق بمقاسات التثبيت
net.js                  طبقة الشبكة (غرف، مزامنة، صوت)
server/                 الخادم الاختياري للعب أونلاين
.nojekyll               يمنع GitHub Pages من تجاهل الملفات
```

## اللعب عبر الشبكة

يوجد خادم اختياري داخل مجلد `server`: غرف برموز، مزامنة فورية، محادثة صوتية بين اللاعبين، وكشف انقطاع الاتصال وضعف الشبكة. التطبيق يعمل كاملاً دون إنترنت إن لم ترفع الخادم؛ اللعب الشبكي إضافة فوقه. راجع `server/README.md` للنشر في خطوتين.

## الميزات

- **ثنائي اللغة** عربي/إنجليزي مع تبديل فوري لاتجاه الواجهة (RTL/LTR).
- **لودو كامل**: ٢–٤ لاعبين، ٤ أحجار لكل لاعب، ٦ للخروج، أكل الأحجار، خانات أمان، ممر البيت، رمية إضافية، ونرد بتوزيع مُنصف يمنع البقاء عالقاً في الصندوق.
- **إكس أو**: فردي ضد حاسوب (Minimax) أو جماعي، مع اختيار الرمزين ومن يبدأ.
- **الذاكرة**: ١٢/١٦/٢٠ بطاقة، فردي بثلاثة مستويات ذكاء أو جماعي.
- مؤثرات صوتية مولّدة داخلياً (Web Audio) بلا ملفات، واهتزاز، وقصاصات احتفال.
- تأكيد قبل مغادرة أي جولة، بما في ذلك زر الرجوع في النظام.
- **ماهجونج** و**خطوط ومربّعات**: لعبتان إضافيتان بلاعبين، بأطقم أعلام ورموز وخمسة ثيمات.
- كل الإعدادات تُحفظ محلياً؛ لا شبكة ولا تتبّع في الوضع المحلي.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً (مثلاً `majlis`) وارفع محتويات هذا المجلد في جذره.
2. من **Settings › Pages**: اختر `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`.
3. انتظر دقيقة، ثم افتح `https://<اسم-المستخدم>.github.io/majlis/`.

> مهم: التثبيت كتطبيق وعامل الخدمة يحتاجان **HTTPS**، وهو مُفعّل تلقائياً في GitHub Pages. جميع المسارات نسبية، فلا حاجة لتعديل شيء مهما كان اسم المستودع.

## التثبيت كتطبيق

- **أندرويد / كروم:** افتح الرابط ← قائمة المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون / سفاري:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **سطح المكتب:** أيقونة التثبيت في شريط العنوان.

بعد التثبيت يعمل التطبيق دون إنترنت تماماً.

## التشغيل محلياً

عامل الخدمة لا يعمل عبر `file://`، فشغّل خادماً بسيطاً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## تحديث النسخة

عند تعديل أي ملف، ارفع رقم النسخة في `sw.js`:

```js
const VERSION = 'majlis-v1.0.1';
```

فيمسح عامل الخدمة الذاكرة القديمة ويجلب الملفات الجديدة عند الفتح التالي.

## بناء مكتفٍ ذاتياً (اختياري)

الاتصال الخارجي الوحيد هو خطوط Google. لإزالته كلياً، احذف وسمَي `<link>` الخاصين بالخطوط من `index.html` و`privacy.html`؛ ستُستخدم خطوط النظام تلقائياً.

## الأمان

- `Content-Security-Policy` مضبوطة داخل الصفحة: لا سكربتات خارجية، ولا `object`، ولا إرسال نماذج.
- `referrer: no-referrer`، ولا تخزين لأي بيانات خارج جهاز المستخدم.
- عامل الخدمة يعترض طلبات النطاق نفسه فقط.
